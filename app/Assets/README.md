# Application assets

`TextPicker.svg`, `TextPicker.png` and `TextPicker.icns` are the canonical
**Contour hug / Medium** artwork: Midnight palette, rounded 48-unit contours and
a 1.76× central mark. `icon.json` records their hashes and geometry parameters.
Packaging copies the ICNS unchanged; tests pin the approved artwork independently
of the manifest. The monochrome menu-bar symbol is separate.
